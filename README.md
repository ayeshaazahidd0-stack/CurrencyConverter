# Currency Converter (Java Swing)
A lightweight desktop application built using Java Swing that converts **Pakistani Rupees (PKR)** into **US Dollars (USD)** and **British Pounds (GBP)** in real-time.
---
## Features
*   **Simple GUI:** Built using Java `JFrame` and `GridLayout` for a clean, user-friendly interface.
*   **Instant Conversion:** Convert PKR to USD and GBP with a single click.
*   **Clear Functionality:** Quickly reset all input fields to start a new calculation.
*   **Precision Formatting:** Displays converted currency values rounded to 2 decimal places.
---
## Tech Stack
*   **Language:** Java (JDK 8 or higher)
*   **GUI Framework:** Java Swing & AWT
---
## How It Works
1. **Input:** Enter the amount in **Pakistani Rupees (PKR)** into the corresponding text field.
2. **Convert:** Click the **Convert** button. The application will calculate and display the equivalent amounts in USD and GBP.
3. **Clear:** Click the **Clear** button to wipe all text fields and start fresh.
> **Note on Conversion Rates:** 
> This application uses hardcoded baseline rates for demonstration purposes:
> *   1 USD = 280 PKR
> *   1 GBP = 350 PKR
